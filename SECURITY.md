# Security Policy

Satya is a Bitcoin fee-estimation tool, and we take security seriously. If you discover a security vulnerability, please report it responsibly.

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 0.1.x   | :white_check_mark: |

Satya is in pre-1.0 development. Security updates are applied to the latest version on `main`.

## Reporting a Vulnerability

**Do NOT open a public issue for security bugs.**

Please report security vulnerabilities using **GitHub's private vulnerability reporting**:

1. Go to the repository's **Security** tab
2. Click **Report a vulnerability**
3. Fill out the advisory form with details of the vulnerability
4. Submit the private report

This ensures the vulnerability is addressed confidentially before public disclosure.

## Response Expectations

- We will acknowledge your report within approximately 72 hours
- We prefer coordinated disclosure: we will work with you on a timeline before any public announcement
- Please allow reasonable time for a fix and release before public disclosure
